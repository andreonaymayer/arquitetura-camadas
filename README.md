# Arquitetura Back-End em Camadas

Painel interativo para aprender o fluxo de dados em um Back-End em camadas: Front-End, Controller, Service, Repository e Banco de Dados.

**Acesse a página:** https://andreonaymayer.github.io/arquitetura-camadas/

Também dá para abrir o `index.html` direto no navegador. Siga o tutorial que abre ao entrar.

## Exemplos em código

- [`exemplo-spring-boot`](exemplo-spring-boot): API REST de produtos e categorias em Spring Boot (Java 21) com PostgreSQL, mostrando Controller, Service e Repository em Java.
- [`exemplo-angular`](exemplo-angular): Front-End em Angular 21 que consome essa API.

Cada pasta tem um README próprio com a instalação no Windows 10 e o passo a passo para rodar.
